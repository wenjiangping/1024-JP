# Go Lita

> 一场为冬天多攒一点的小冒险：2D 横屏、4:3、单人森林收集跑酷
>
> 游戏设定 v0.1.7｜2026-10-25
>
> 本版把积分、称号和难度绑定到同一条 30 分进度线；开启 XBuilder 全局物理属性；保留现有操作按钮的位置与大小；补充运行后首个键盘输入的处理边界与验证方法。

## 1. 游戏定位

冬天快到了，Lita 沿森林小径寻找蘑菇与水晶。她要在自动向前推进的路上选择位置、跳过实体障碍、避开火焰和炸弹，把尽可能多的收获带回家。

画面保持 480 × 360、4:3 横屏和明亮扁平卡通森林。游戏继续采用单人、单一循环地图和积分模式，不制作多个独立关卡；路段通过受约束的随机组合产生变化。

本轮继续使用 XBuilder 项目 En / IdeaDash 的默认 Lita、已有动作、草地、云、蘑菇、水晶、火焰、炸弹及底部操作按钮。按钮的位置和大小属于已确认的交互设计资产，后续代码和资源更新不得改动它们。

## 2. 积分、称号与难度

### 2.1 计分公式

`囤粮分 = 蘑菇数量 × 1 + 水晶数量 × 3`

只记录实际收获。时间、距离、跳跃、躲避、顶住实体障碍和踩过台阶都不加分；暂停和结束状态不收集；每件物品只领取一次。继续保留蘑菇 +1、水晶 +3，使玩家能通过选择高处水晶明显提高分数。

### 2.2 30 分阶段

阶段编号为 `DifficultyStage = floor(囤粮分 / 30)`。每满 30 分进入下一阶段，阶段变化立即更新称号、速度和路段密度。阶段 0 从 0 分开始；为避免后期数值失控，速度与密度最多按阶段 6 计算，分数仍可继续累积。

| 分数 | 阶段 | 称号 | 体验提示 |
|---:|---:|---|---|
| 0–29 | 0 | 蹦跶小新手 | 熟悉移动、跳跃和收集 |
| 30–59 | 1 | 树影穿梭客 | 森林开始加快脚步 |
| 60–89 | 2 | 灌木飞毛腿 | 实体障碍组合增加 |
| 90–119 | 3 | 林间寻路家 | 上下路线和危险更常见 |
| 120–149 | 4 | 风之探险家 | 路段节奏明显加快 |
| 150–179 | 5 | 森林传说 | 高分路线需要连续判断 |
| 180 以上 | 6 | 森林守护者 | 最高常规难度，继续挑战高分 |

### 2.3 难度随积分增长

- 速度以 58 为基准，每进入一个阶段提高基准速度的 10%，即阶段 1 为 63.8、阶段 2 为 69.6，阶段 6 为 92.8；速度达到阶段 6 后不再继续增加。
- 障碍密度以阶段 0 为 100%，每阶段增加 10% 的额外障碍出现机会。实现上使用额外障碍槽和受约束概率，不强行把两个对象塞进同一个起跳点。
- 阶段 0 保持练习空间；阶段 1 先增加单个实体；阶段 2 以后才逐步加入双实体、火焰或炸弹组合。每次连续挑战后仍插入补给路，避免只因分数高就生成无解路段。
- 速度和障碍密度根据已经获得的分数变化，而不是根据存活时间变化。分数冻结时，难度阶段也冻结；重试恢复 0 分、阶段 0 和初速。

## 3. 障碍分类与结束条件

| 类别 | 对象 | 行为 | 是否立即结束 |
|---|---|---|---|
| 实体障碍 | 石头、树桩、乱石堆 | 侧面阻挡并随地图滚动推挤；从上方可站立或跳过 | 否 |
| 地形实体 | 草地、草台、台阶侧壁 | 上表面提供支撑，侧面阻挡；明显高差需要跳跃 | 否 |
| 危险障碍 | 火焰、炸弹 | 身体进入有效危险区域即结束；炸弹随后播放一次已有爆炸动画 | 是 |
| 缺口 | 草地之间的空档 | 没有真实支撑时持续下落 | 落出下边界后结束 |
| 收集物 | 蘑菇、水晶 | 领取一次后消失并加分 | 否 |
| 装饰 | 白云、背景 | 不碰撞、不计分 | 否 |

本游戏只有三种结束：

1. 碰到火焰、炸弹等危险障碍。
2. 被实体障碍持续推挤，使 Lita 的有效身体完全越过左侧可玩边界。
3. 失去草地或实体顶部支撑，身体落出下边界。

普通实体接触当帧不能直接结束，也不能用固定 X 坐标把角色锁在屏幕中而掩盖被推挤结局。尾巴和素材透明边距不参与危险判定；碰撞使用角色身体和脚部。

## 4. 物理属性与角色层级

XBuilder 舞台开启全局物理属性。角色采用 **Kinematic** 物理模式：由代码控制左右移动和自定义跑酷重力，同时参与碰撞；草地、草台和实体障碍采用 **Static** 物理模式，作为可碰撞的固定支撑；云、收集物、按钮和纯装饰保持 **None**，避免干扰路线。

全局物理开关、精灵物理模式和碰撞形状必须与本规则保持一致。手写逻辑负责地图滚动、可控的跳跃宽限、危险结算和越界结算，避免 XBuilder 物理引擎的自动重力破坏循环地图。两套系统不重复施加重力。

Lita 的绘制层保持 Front，始终显示在草地、台阶、收集物和障碍之上；按钮继续使用原位置、原尺寸和原碰撞区域。

## 5. 输入和首次按键

| 输入 | 作用 |
|---|---|
| ← / A、→ / D | 左右移动并转向 |
| Space / ↑ / W | 单次跳跃，长按不连跳 |
| 底部左右箭头、上箭头 | 鼠标或触屏移动、跳跃 |
| P / 暂停按钮 | 暂停、继续 |
| R / 回转按钮 | 清空本局并重试 |

新局初始化 `jumpHeld`、方向输入和按钮状态均为释放状态，不能把第一下按键误判成“已长按”。项目通过事件型键盘处理配合帧内状态采样，减少运行按钮仍保持焦点时的输入丢失。验证时必须点击“运行”后直接按键，不额外点击游戏画面；若浏览器外层焦点仍停留在编辑器，需在验收记录中区分 XBuilder 预览焦点问题与游戏脚本问题。

## 6. 路段与节奏

- 五个循环地形槽组合补给平地、单实体、乱石与水晶、悬浮草台、树桩加火焰、炸弹、台阶、双实体和短缺口等路线。
- 开局前至少三个路段用于练习；阶段 0 前 8 秒不出现危险，前 20 秒不安排必过缺口。
- 每个路段最多两个障碍，额外障碍按阶段概率加入，并留出起跳、落地和恢复空间。危险前后保留清楚安全区，缺口宽度仍受实测跳跃能力限制。
- 连续两个挑战后插入补给路；水晶可以放在实体上方或悬浮草台上，蘑菇优先放在安全地面。奖励不能埋进障碍碰撞盒。
- 重试清理所有旧克隆、爆炸动画和音效，恢复默认炸弹造型、0 分、阶段 0 和安全起步。
