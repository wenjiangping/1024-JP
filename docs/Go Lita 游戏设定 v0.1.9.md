# Go Lita

> 游戏设定 v0.1.9｜2026-10-25  
> 2D 横屏 · 480 × 360（4:3）· 单人森林收集跑酷

## 1. 世界观与定位

冬天快到了，松鼠 Lita 沿森林小径收集蘑菇与水晶。她在不断推进的小径上寻找落脚点、跨过实体障碍、躲开危险，把尽可能多的收获带回家。采用一个循环森林场景，以收集积分挑战高分，保留明亮卡通森林、Lita 原有动作和物理碰撞。

## 2. 计分与严格阶段映射

`囤粮分 = 蘑菇数量 × 1 + 水晶数量 × 3`。仅实际收获加分；时间、距离、跳跃与躲避不计分。暂停、说明、首页和结算状态不计分。每件收集物每次生成只能领取一次。

`阶段 = min(floor(囤粮分 / 20), 5)`。只保留阶段 0–5，不再使用“森林传说”或阶段 6。100 分以后持续累计分数，称号与难度保持阶段 5。

| 阶段 | 囤粮分 | 称号 | 成就图片 | 速度（像素/秒） | 障碍密度倍率 |
|---:|---|---|---|---:|---:|
| 0 | 0–19 | 蹦跶小新手 | 无升级弹窗 | 58.00000 | 1.00000 |
| 1 | 20–39 | 树影穿梭客 | 成就1.png | 75.40000 | 1.30000 |
| 2 | 40–59 | 灌木飞毛腿 | 成就2.png | 98.02000 | 1.69000 |
| 3 | 60–79 | 林间寻路家 | 成就3.png | 127.42600 | 2.19700 |
| 4 | 80–99 | 风之探险家 | 成就4.png | 165.65380 | 2.85610 |
| 5 | 100 以上 | 森林守护者 | 成就5.png | 215.34994 | 3.71293 |

每个阶段的速度、目标障碍密度都等于上一阶段的 **130%**，即 `倍率 = 1.3 ^ 阶段`。不能沿用每阶段增加基准值 10%、30 分升级或额外第六阶段的旧规则。HUD、升级图片、结算称号共用同一阶段编号和称号表，达到阈值（含水晶加分跨过阈值）时立即更新。

### 障碍数量如何增长

以每个可布置路段目标 0.5 个障碍为基准，各阶段目标数量为 0.5 / 0.65 / 0.845 / 1.0985 / 1.42805 / 1.856465。生成器把小数累积为障碍配额，再取整数生成，避免把 0.65 个障碍直接取整为 0。升级时清空小数配额，按新阶段密度生成后续离屏路段。已经出现在玩家面前的地形不突然增加障碍。

这是对可布置路段的目标密度约束；开局练习区、缺口起落区和连续挑战后的补给路仍保留。每段最多两个障碍，双障碍间隔至少约 130 像素；这些安全路段不消耗可布置路段的配额。整数障碍数随具体随机路线波动，不能保证每个短局的实际总数刚好相差 30%。

## 3. 页面与状态流程

`点击 XBuilder 运行 → 首页 → START → 游戏说明 → 点击说明弹窗任意位置 → 游戏 → 失败 → 结算`

| 状态 | 显示内容 | 允许操作 | 地图与积分 |
|---|---|---|---|
| 首页 | 开始封面.png，START 按钮 | 点击 START（Enter/Space 亦可） | 冻结；不展示局内控件 |
| 游戏说明 | 静止森林、半透明遮罩、游戏开始说明.png | 点击整张说明弹窗任意位置，包括图中的关闭图标和 START GAME；Enter/Space 亦可 | 冻结；开始前清零 |
| 游戏进行 | 森林、分数与称号、五个新操作按钮 | 左右移动、跳跃、暂停、重试 | 正常推进和收集 |
| 暂停 | 原场景与暂停提示，暂停键切换为继续图标 | P / 暂停键继续；重试可开始新局 | 地图、分数、成就计时冻结 |
| 游戏结算 | 冻结的本局场景、遮罩、game over.png、实时本局分数与称号、RESTART、HOME | RESTART / R 直接重开；HOME 返回首页 | 冻结；结果保持 |

RESTART 跳过已看过的说明直接开新局；从 HOME 再点 START 则再次展示说明。结算显示实际本局分数与对应称号，不能使用截图中的 126 等示例数字。失败原因仍由危险接触、挤出画面、踩空掉落决定。结算、首页与重试都会清理上一局成就和残留按键，说明关闭的那次点击不能穿透为跳跃。

## 4. 成就称号效果

阶段 0 只显示 HUD 称号。每局首次跨过 20 / 40 / 60 / 80 / 100 分时，依次使用成就1–5.png。图片显示在画面上部中央，宽度约 280 舞台像素，保持原始比例；保留约 1.6 秒后淡出约 0.35 秒。升级图片不遮挡脚下路线和底部按键，不拦截操作，游戏继续运行。暂停期间成就倒计时也暂停。

同一阶段每局只展示一次；跨阈值后使用新阶段图片，不重复播放旧称号。失败或返回首页立即关闭成就层；重试从阶段 0 开始，下一局可以重新获得五个成就。图片、HUD 与结算的阶段必须严格一致。

## 6. 核心跑酷与物理

保留 XBuilder 舞台全局物理开关。Lita 为 Kinematic，草地、草台、石头、树桩、乱石堆为 Static；装饰、收集物、按钮与页面图层为 None。由角色代码施加重力与跳跃、处理实体顶部/侧壁和边界结算，避免重复施加引擎重力。Lita 在世界元素上层，页面与成就层在 Lita 之上。

| 类别 | 对象与作用 | 结算 |
|---|---|---|
| 实体 | 石头、树桩、乱石堆、台阶：侧面阻挡，顶部可落脚 | 接触不失败；被持续挤出左边界才失败 |
| 危险 | 火焰、炸弹：有效身体接触 | 立即结束；炸弹播放一次爆炸 |
| 缺口 | 失去草地支撑后持续下落 | 身体完全落出底边后失败 |
| 收集物 | 蘑菇、水晶 | +1 / +3，领取一次后隐藏 |

保留离地宽限、跳跃缓冲、尾巴不参与危险碰撞、长按不自动连跳。左右键/A/D 移动，Space/↑/W 跳跃，P 暂停，R 重试；按键事件只在对应页面状态有效。开局三个路段安全，后续通过循环地形、缺口、草台和实体组合增加变化。
