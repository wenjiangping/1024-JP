# Go Lita

> 一场为冬天多攒一点的小冒险：2D 横屏、4:3、单人森林收集跑酷
>
> 游戏设定 v0.1.6｜2026-10-25
>
> 本版新增实体障碍、危险障碍及三种结束条件，补充炸弹表现、开局输入与更丰富的收集路线。v0.1.4、v0.1.5 保留作历史版本。

## 1. 定位与世界观

冬天快到了，Lita 沿森林小径寻找食物和闪亮的宝藏。她会遇到挡路的石头、树桩和草地台阶，也要躲开火焰与炸弹。玩家用移动和跳跃选择路线，把更多蘑菇与水晶带回家。

核心体验是：**看清路况，跳过阻挡，抓住收获，向森林更深处探索。** 不需要制作多个关卡，而是在同一森林内循环生成有变化、可通过的路段。

| 项目 | 约定 |
|---|---|
| 名称 | Go Lita；账号 En，XBuilder 项目标识 IdeaDash |
| 画面 | 480 × 360、4:3 横屏，明亮的扁平卡通森林 |
| 主角 | 平台默认 Lita，复用 Walk、Jump、Fall 等已有动作 |
| 类型 | 单人自动推进跑酷，可左右选位、跳跃和收集 |
| 本轮界面 | 积分、称号、底部操作按钮；直接进入游戏，暂不制作独立开始/说明/结算页 |

## 2. 障碍必须有明确分类

| 类别 | 对象 | 碰到后的行为 | 是否直接结束 |
|---|---|---|---|
| 实体障碍（静止障碍物） | 石头、树桩、可站立石块/木箱等 | 身体不能穿过去；从侧面接触时阻挡移动，随地图滚动可把 Lita 推向画面左边；成功跳过或从上方落在可站立顶部可继续跑 | 否 |
| 地形实体 | 草地台阶、草台侧壁 | 上表面可落地，侧面阻挡；高差需要跳跃，不能从侧面被吸到台阶顶部 | 否 |
| 危险障碍 | 火焰、炸弹 | 身体进入有效危险区域即结束；尾巴不参与危险判定 | 是 |
| 缺口 | 草地之间的空档 | 没有支撑时持续下落，只有落到真实表面才停下 | 掉出下边界后结束 |
| 收集物 | 蘑菇、水晶 | 领取一次后消失并加分，不阻挡、不造成失败 | 否 |
| 装饰 | 云、背景等 | 不碰撞、不计分，不与危险使用同一外观 | 否 |

“静止”指障碍固定在森林路面上，仍会随画面滚动向左移动。角色碰到石头或树桩时不立刻失败，也不扣分。玩家可以及时跳起脱困；一直不处理，才会被推离画面。

普通地面很小的高低差可平顺衔接，明显台阶与实体侧壁必须阻挡。悬浮草台应明确其实体边界，不再把所有草台侧面都视为可穿透区域；生成时为下层路线保留足够净空，或用收集物清楚引导跳到上层。

## 3. 仅有三种结束机制

1. **危险接触**：碰到火焰、炸弹等危险障碍。
2. **被挤出画面**：石头、树桩或地形侧壁持续阻挡、推挤，使角色的有效身体完全越过左侧可玩边界。不能用固定的最小 X 坐标把角色永久锁在屏幕内，也不能刚碰到边缘就失败。
3. **踩空掉落**：失去草地或实体顶部支撑后落出下边界。

结束时立即冻结本局计分、地图推进与生成。允许已触发的炸弹完成一次爆炸演出；场内用 Lita 的简短气泡说明失败原因和重试方式，不恢复被删除的顶部文字提示控件。重试必须恢复安全地形、默认炸弹形态、初速、零分和新手称号，并清理旧克隆/爆炸状态。

## 4. 炸弹与反馈

- 使用用户新增的“炸弹”精灵及其已有爆炸动画。正常状态固定显示炸弹造型，不循环播放爆炸。
- 有效身体接触后，立即锁定本局为结束状态，触发一次爆炸动画。爆炸是接触后的表现，不扩大隐形伤害范围，也不要求等待动画播完才停止计分。
- 同一炸弹只触发一次，不因逐帧重叠重复播放、重复结算或连续响声。
- 重试时中止上一局爆炸演出，恢复默认造型，不能让旧动画污染新一局。
- 火焰可以持续播放已有燃烧动画。收集物可使用轻量领取音，炸弹可使用短促爆炸音；音量保持克制，不叠加持续噪声。
- 素材库补充的障碍也必须加入上述分类；不能因换外观而悄悄改变碰撞性质。

## 5. 积分与称号

**囤粮分 = 蘑菇数量 × 1 + 水晶数量 × 3。**

只记录实际收获，不给时间、距离、跳跃、顶住障碍或脱困加分。每件物品只领取一次，暂停/结束不加分，漏捡不扣分。收集物不与危险或实体内部重叠。

| 分数 | 称号 |
|---:|---|
| 0–4 | 蹦跶小新手 |
| 5–11 | 树影穿梭客 |
| 12–23 | 灌木飞毛腿 |
| 24–39 | 林间寻路家 |
| 40–59 | 风之探险家 |
| 60 以上 | 森林传说 |

保留积分与称号控件。删除截图中显示“歇歇尾巴 · 按 P 继续”等文字的 **Hint/提示控件**，不删除底部操作按钮。短暂反馈优先通过物品消失、音效、称号变化或角色气泡表达。

## 6. 输入、重力与角色层级

| 输入 | 作用 |
|---|---|
| ← / A，底部左箭头 | 左移并朝左 |
| → / D，底部右箭头 | 右移并朝右 |
| Space / ↑ / W，底部上箭头或点击上部游戏区域 | 单次跳跃 |
| P / 底部暂停按钮 | 暂停、继续 |
| R / 底部回转箭头 | 重试 |

运行加载完成后，第一下有效跳跃输入应能使用，不能因初始化把第一次按键当成“已长按”而丢弃。键盘验证必须在未额外点击游戏画面的情况下进行，避免测试工具自动聚焦掩盖预览焦点问题。若阻碍来自 XBuilder 外层预览焦点，需要在实现记录中如实说明范围，不能将临时手动点击记为持久修复。

持续施加重力，脚底按可见角色校准；空中不能隐形站立。保留短暂离地宽限和落地前输入缓冲，长按不自动连跳。Lita 保持在平台、障碍和装饰前层；碰撞采用身体与脚部，排除尾巴和素材透明边距。

## 7. 路段变化与温和难度

增加实际路面上能看见的障碍比例，不只增加素材名称：

- 安全补给路：蘑菇与少量水晶，让玩家调整节奏。
- 实体练习路：单个石头/树桩，前后有起跳与落地空间。
- 宝藏跳跃路：在水晶路线之间或下方安排一个明确的阻挡，引导跳跃领取；不把奖励埋入障碍。
- 草地台阶路：看得见的高差与侧壁，可跳上再继续跑。
- 危险躲避路：火焰或炸弹前后保留清楚的安全区。
- 上下分路：地面有补给，上层有水晶；可选路线不强迫进行连续精准操作。
- 短缺口路：间距由实测跳跃能力限制，前后不堆叠危险。

开局至少前 8 秒没有需要躲避的障碍，前 20 秒不安排必过缺口。之后先出现单个实体，再逐步混入危险与组合。较早路段以单障碍为主，后续允许同一路段有两个间距足够的对象；连续挑战后插入缓冲路，避免一串无解障碍。

维持初始速度 58，每 30 秒增加初始值约 4%，封顶 1.25 倍。随机生成必须约束障碍间距、跳跃净空、缺口起落点及收集路线，不在角色脚下突然生成、变高或变成危险。

## 8. 实现与存档

舞台负责状态、积分、难度、路段池和帧协调。Lita 负责输入、重力、实体碰撞与推出边界判定；石头、树桩、炸弹、火焰、收集物和按钮分别保留自己的脚本。绘制坐标受 SPX 边缘限制时，使用独立逻辑坐标判断真实越界，不能被绘制钳制掩盖。
