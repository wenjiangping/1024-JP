# Go Lita runner v0.1

这是在 XBuilder 的 `IdeaDash` 项目中完成的第一版可玩跑酷实现。完整项目包保存在 `Go-Lita-runner-v0.1.xbp`；`main.spx` 是同一份导出项目中的可读舞台脚本，便于后续审阅和继续修改。

## 导入与运行

1. 在 XBuilder 项目菜单选择“导入项目文件”。
2. 选择 `Go-Lita-runner-v0.1.xbp`。
3. 导入后点击“运行”预览；本次制作没有发布项目。
4. 游戏运行时按 `Space` / `Up` 或点击预览区域跳跃；碰到火焰后按 `R` 重试。

## 本版范围

- Lita 自动向右奔跑，使用已有 Walk、Jump、Fall 动画。
- 连续草地是主路；较高草台提供可选的跳跃路线。
- 蘑菇 +50 囤粮分，水晶 +100 囤粮分；有效奔跑每秒 +10。
- 前 8 秒不生成火焰；火焰按低频率出现，速度每 30 秒按初始速度的 4% 缓慢增加，封顶 1.25 倍。
- 采用固定对象池回收道具和火焰，不创建无限克隆。
- 暂不包含开始页、玩法说明页和游戏结束页，符合本次迭代范围。

## 验证记录

- 预览成功运行并显示 `囤粮分` 控件，控件绑定舞台变量 `Score`。
- 控制台确认蘑菇、水晶分别加分。
- 确认长按不会连续触发跳跃；确认 Lita 可以从上方落到草台并收集草台水晶。
- 确认碰到火焰后停止计分，按 `R` 可清空本局并重新开始。
- 全程未点击 XBuilder 的“发布”按钮。

## 资产说明

`.xbp` 已包含本项目导出时的脚本、配置、背景、精灵造型、动画和声音。当前版本继续使用项目中已有的临时素材，后续可在 XBuilder 内替换而不改变核心脚本结构。
