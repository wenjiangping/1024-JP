# Go Lita runner v0.3

480 × 360、4:3 的单人森林收集跑酷。本版把障碍拆成**实体阻挡**与**危险接触**，增加乱石堆、炸弹和收集路线，并把积分、称号、速度和障碍机会统一到每 30 分一个阶段。规则对应 [文档 PR #2](https://github.com/wenjiangping/1024-JP/pull/2) 中的 v0.1.8。

## 打开与操作

云端：[En / IdeaDash，显示名 Go Lita](https://x.qiniu.com/editor/En/IdeaDash/stage/code)。工程已保存到原项目，点击“运行”试玩，无需发布。

本地恢复：先导出需要保留的当前修改，再通过项目菜单导入 **Go-Lita-runner-v0.3.xbp**。包内包含完整源码、背景、精灵、动画和声音。旧版本可从 Git 历史恢复。

| 输入 | 操作 |
|---|---|
| ← / A，→ / D | 左右移动并转向；松开后森林继续向左推进。运行后第一下方向键也会保留约 12 帧输入 |
| Space / ↑ / W | 单次跳跃，长按不连跳 |
| 底部左右箭头、上箭头 | 屏幕移动与跳跃；按钮位置、大小和碰撞区域保持原设计 |
| 点击上部游戏区域 | 跳跃；底部按钮区域独立处理 |
| P / 暂停按钮 | 暂停、继续 |
| R / 回转箭头 | 清空本局并重试 |

保留积分、称号和底部五个操作按钮；删除原顶部 Hint/提示控件。暂停和结束信息通过角色气泡表达。本轮没有独立开始、介绍、结算界面。

## 规则

- **蘑菇 +1，水晶 +3**。分数恒等于 `Mushrooms + Diamonds * 3`；时间、距离、跳跃不加分。物品只领取一次，暂停和结束不收集。
- 每 30 分升级一次称号和难度：0–29 蹦跶小新手、30–59 树影穿梭客、60–89 灌木飞毛腿、90–119 林间寻路家、120–149 风之探险家、150–179 森林传说、180+ 森林守护者。
- 速度以 58 为基准，每阶段提高基准值的 10%，阶段 6 封顶为 92.8；障碍使用额外槽位按阶段增加 10% 的出现机会，连续挑战后插入补给路。
- **石头、树桩、乱石堆、草地侧壁**属于实体。侧面阻挡并随滚动向左推角色，接触不扣分、不立即结束；从上方可以落在实体顶部。
- **火焰、炸弹**属于危险。角色身体进入有效区域立即结束；尾巴不参与危险判定。炸弹平时显示默认造型，接触后播放已有 32 帧爆炸一次，立即冻结计分和地图；重试清理旧克隆与动画。
- 只有三种结束：危险接触、有效身体完全被推过左边界、失去支撑后身体落出下边界。
- 重力 560、起跳速度 335，跳跃高度约 100 像素。保留 0.11 秒离地宽限、0.12 秒输入缓冲。明显台阶及悬浮草台侧壁阻挡，最多 8 像素的小高差可平顺衔接；草台下保留至少 50 像素净空。
- 新局初始化方向、跳跃和按钮状态为释放；事件型键盘输入配合帧内状态采样，避免运行后第一下输入丢失。P/R 事件直接触发并由按键状态防止长按重复切换。
- Lita 每帧保持场景前层。朝向切换围绕身体进行，避免翻尾巴造成碰撞体突然横移。

## 物理配置

舞台 `assets/index.json` 开启全局 `physics: true`。Lita 使用 `kinematic`；草地、草台、石头、树桩、乱石堆、火焰和炸弹使用 `static`；云、蘑菇、水晶和五个操作按钮使用 `no`。代码仍负责循环地图、手动跑酷重力、碰撞和结束结算，避免 XBuilder 物理引擎重复施加重力。

## 路段与难度

五个循环地形槽组合补给平地、单实体、乱石与水晶、悬浮草台、树桩加火焰、炸弹、台阶、双实体和短缺口等路线。开局前三段用于练习，阶段 0 前 8 秒不出现危险，前 20 秒不安排必过缺口。每个路段最多两个障碍，额外障碍留出起跳、落地和恢复空间；水晶可放在实体上方或上层路线，蘑菇优先放在安全地面。

固定池共 70 个克隆：5 个草台、15 个收集物、5 种障碍各 10 个；离屏循环槽位，重试先清理旧克隆。随机模板受安全间距、前后安全区和挑战连段限制，不保证随机组合穷举完毕。

## 检查与打包

只需 Python 3，无第三方依赖：

```powershell
python game/tools/package_project.py --check
python game/tools/package_project.py
```

第一条检查 4:3 舞台、全局物理、按钮几何、资源路径、动画首尾帧、精灵及声音顺序、删除的 Hint 监视器、测试布局隔离、压缩包无重复/损坏项以及全部文件与源码逐字节一致；第二条在编辑 `project/` 后重建包。资源检查不代替 XBuilder 的实际编译和试玩。

需要复现单项碰撞时运行 `python game/tools/create_playtest_project.py`，临时包写入本任务根目录的 `other/` 子目录，不修改正式工程。

`Parkour Game.zip` 是用户提供的 Unity 成品参考，未执行、未搬用其 EXE/DLL 或素材。XBuilder 官方仓库只读参考。游戏未发布，PR 保持打开、不合并。
