# Go Lita v0.3 验收记录

2026-10-25，账号 En / 项目 IdeaDash，XBuilder SPX 3.3.0 浏览器预览，480 × 360。对应规则文档 v0.1.8。使用实际键鼠输入、可见画面和页面控制台验证；没有发布。

## 本轮更新

- 积分阶段改为每 30 分一档，称号与难度同步变化。
- 速度按阶段使用 `58 × (1 + stage × 0.10)`，阶段 6 封顶 92.8；额外障碍机会为每阶段 10% 的增量。
- 舞台开启全局物理；Lita 为 Kinematic，地形和障碍为 Static，装饰、收集物和按钮保持 None。
- 方向键事件保留 12 帧输入脉冲；P/R 事件直接触发，降低运行后第一下键盘输入丢失的概率。
- 底部五个按钮的坐标、尺寸和碰撞区域未修改：MoveLeft (-210,-150,1)、MoveRight (-160,-150,1)、JumpButton (-110,-150,1)、PauseButton (160,-150,1)、RetryButton (210,-150,1)。

## 云端编译与首键验证

导入 `Go-Lita-runner-v0.3.xbp` 后点击“重新运行”，控制台出现 `DIFFICULTY 0 0`、`START 1` 和 `PACE 0 58 0`，说明工程编译、启动和初始阶段均正常。

未点击游戏画布，直接通过当前预览焦点发送键盘输入：

- `space` 后出现 `JUMP -129.28 -102`，首个跳跃输入生效。
- `Right` 在同一轮发送，Lita 的水平方向输入被接收；事件保留脉冲，未依赖额外鼠标点击。
- `P` 后出现 `PAUSE true 4 ...`，再次按 `P` 后出现 `PAUSE false 4 ...`。
- `r` 后出现 `DIFFICULTY 0 0`、`START 2` 和 `PACE 0 58 0`，重试清空状态并恢复阶段 0。

详细本轮日志见 [qa-v018-log.txt](evidence/qa-v018-log.txt)。

## 范围与限制

本轮没有对所有外部浏览器、窗口切换、手机多点触控、十分钟以上连续运行、弱设备帧率或内存仪表长测做专项验证。随机模板出现不等于每种组合都已穷举通关。独立开始、介绍和结算页留待后续；项目未发布，PR 不合并。
