# Go Lita 森林收集跑酷

这是一个基于 XBuilder 制作的 4:3 横屏单人跑酷游戏。玩家控制 Lita 穿越森林，收集蘑菇和水晶储备粮食，躲避火焰、炸弹、石头和缺口，并挑战更高分数与称号。

## 在线体验

[打开已发布的 Go Lita 游戏](https://x.qiniu.com/project/En/IdeaDash)

## 操作玩法

- ← / → 或 A / D：左右移动
- 空格、↑、W 或绿色跳跃键：跳跃
- P / Esc：暂停或继续
- R：重新开始；结算页按 Enter 可快速重开
- 蘑菇 +1 分，水晶 +3 分；碰到危险物或掉出道路会结束本局

## 故事背景

Lita 是一只生活在森林里的小探险家。为了储备过冬粮食，它踏上森林跑酷之旅，沿途收集蘑菇和水晶，同时躲避危险与障碍，努力成为森林守护者。

## 完整玩法与页面流程

首页点击 START（或 Enter）打开说明，再点击说明图（或 Enter）开始。森林自动向左推进；左右键调整位置，跳跃跨过障碍和缺口。按住跳跃不会连续起跳。屏幕下方左组三键为左移、右移、跳跃，右组为暂停/继续和重开，两组距画面外边缘均为 14 个舞台像素。

| 操作 | 键盘 / 屏幕 |
|---|---|
| 左右移动、转向 | ← / →、A / D、绿色左右键 |
| 单次跳跃 | Space、↑、W、绿色上箭头、点击游戏上部 |
| 暂停与继续 | P、Esc、右组暂停键 |
| 清空本局重开 | R、右组重开键；结算页 Enter / RESTART |
| 返回首页 | 结算页 HOME |

首页、说明、暂停及结算均不推进地图或计分。首页与说明页播放背景音乐，跑酷与结算停止背景音乐。键盘操作前需使游戏画面获得焦点。

## 积分、阶段和称号

**囤粮分 = 蘑菇数量 + 水晶数量 × 3**。蘑菇 +1、水晶 +3；时间、距离、跳跃和躲避本身不加分。同一件收集物每次生成只领取一次，暂停和结束后不能领取。危险判定先于当帧收集，失败后不会补加分。

阶段 0–6 每档 30 分；阶段 7 从 210 分开始，之后每档 50 分，最高称号阶段为 10：

| 阶段 | 囤粮分 | 称号 | 速度（舞台像素/秒） | 可布置路段实际障碍配额 |
|---:|---|---|---:|---:|
| 0 | 0–29 | 蹦跶小新手 | 58 | 1 |
| 1 | 30–59 | 树影穿梭客 | 75.4 | 1.3 |
| 2 | 60–89 | 灌木飞毛腿 | 98.02 | 1.69 |
| 3 | 90–119 | 林间寻路家 | 127.426 | 2 |
| 4 | 120–149 | 风之探险家 | 165.6538 | 2 |
| 5 | 150–179 | 森林守护者 | 215.34994 | 2 |
| 6 | 180–209 | 林海追风侠 | 215.34994 | 2 |
| 7 | 210–259 | 秘境开拓者 | 215.34994 | 3 |
| 8 | 260–309 | 星辉守望者 | 215.34994 | 3 |
| 9 | 310–359 | 万木守护神 | 215.34994 | 3 |
| 10 | 360+ | 森林传说王 | 215.34994 | 3 |

精确计算：低于 210 分时 `阶段 = floor(Score / 30)`；从 210 分起为 `min(7 + floor((Score - 210) / 50), 10)`。速度为 `58 × 1.3^min(阶段, 5)`，150 分起保持原上限。分段变化同步更新称号、成就和难度；水晶跨档同样生效。阶段 1–10 使用对应成就插图，显示 1.6 秒再淡出 0.35 秒，暂停时计时冻结。

运行页囤粮分/称号由 XBuilder 系统 Monitor 读取 `Score` / `Rank`。结束瞬间冻结为 `FinalScore` / `FinalRank`，结算页用原版橙色文字展示；后续重绘、输入、重复结束均不会改变结果。重开清空本局和旧成就。会话最高分保留到刷新，但不显示“新纪录！”气泡。

## 障碍、危险物与路线规则

石头、木桩、石堆为实体：可落在顶部，侧面会阻挡并随地图推挤，接触不会立即结束。火焰和炸弹为危险物，角色有效身体触碰即结束；炸弹触碰后播放一次爆炸。角色身体完全被挤出左侧或落出下边界也会结束，尾巴不计入危险判定。

五个循环路段组合平地、草台、台阶、短缺口和障碍。开局三段安全，每连续两个有挑战的路段后保留补给缓冲；缺口起跳和落地区域不布置障碍。这些安全路段不消耗障碍配额，所以表中配额针对**允许布置障碍的路段**，不代表每段地图都有障碍。

阶段 0–6 延续累计小数配额：`min(1.3^min(阶段,5), 2)`；阶段 7–10 实际配额为每个可布置路段 3 个，取消原来的两个障碍限制。每段独占三个槽位，共 15 个；第三个障碍的清理、滚动、碰撞、渲染和危险检测一起更新，防止跨路段写入。

有危险物资格的进度仍从约 1100 舞台像素后开始。原来仅路线模板 6 生成炸弹，现在模板 6 和 8 都生成炸弹，使各阶段炸弹路线机会约为原来的 2 倍；模板 5 和 9 继续生成火焰。双障碍危险路段保留一个实体和一个危险物；阶段 7–10 的三障碍危险路段为一个实体加两个火焰或两个炸弹，明显提高高分危险物数量。三障碍以 66 像素中心间距排列，留出路段两侧空间；旧双障碍间距规则保持。实际数量会受随机模板、缺口和安全缓冲影响。

角色重力为 560、起跳速度为 335，支持约 0.11 秒离地宽限和 0.12 秒跳跃输入缓冲。木桩和石堆图片下移 4 像素贴合地表，碰撞几何保持原值。

## 工程、验证与历史文档

项目采用 SPX/XGo 与 XBuilder 工程结构：[`main.spx`](game/project/main.spx) 管理分数阶段和地图，精灵脚本负责输入、物理和渲染；舞台为 480×360，全局物理开启。封面及自动缩略图使用 HomeCover，十张成就图沿用原展示大小。
