# Go Lita 森林收集跑酷

这是一个基于 XBuilder 制作的 4:3 横屏单人跑酷游戏。玩家控制 Lita 穿越森林，收集蘑菇和水晶储备粮食，躲避火焰、炸弹、石头和缺口，并挑战更高分数与称号。

## 在线体验

[打开已发布的 Go Lita 游戏](https://x.qiniu.com/project/En/IdeaDash)

## 操作玩法

- ← / → 或 A / D：左右移动
- 空格、↑、W 或绿色跳跃键：跳跃
- P / Esc：暂停或继续
- R：重新开始；结算页按 Enter 可快速重开
- 蘑菇 +1 分，水晶 +3 分；碰到危险物或掉出道路会结束本局

## 故事背景

Lita 是一只生活在森林里的小探险家。为了储备过冬粮食，它踏上森林跑酷之旅，沿途收集蘑菇和水晶，同时躲避危险与障碍，努力成为森林守护者。
